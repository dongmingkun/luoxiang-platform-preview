# 模型载入验收 · 2026-11-27

## 复现截图

检查时，线上教学与结构页面均返回 HTTP 200，预览站的男性 GLB、经络 JSON 与教学页引用的 Vue 入口返回 404。工作台同时显示失败提示和载入中徽标。桌面 8020 服务提供了已整合的男女模型和配套经络数据。

## 浏览器实测

| 操作 | 观察结果 |
| --- | --- |
| 在 8020 打开教学案例 | 进入就绪状态，男性场景有 14 个器官、26 条经络对象 |
| 打开人体结构并切换女性 | 索引可用，女性模型含 14 个器官结构、354,643 个三角面 |
| 在浏览器内模拟无模型的 Pages 发布，打开教学页 | 直接显示文件选择入口，等待状态无转圈，返回本机的链接保留当前教学案例 |
| 只选男性 GLB，再选不符合经络格式的 JSON，最后补选正确文件 | 分别显示缺失文件名与格式错误，补齐后在同一页显示模型 |
| 同时提供男女两组文件，切换女性 | 女性场景有 14 个器官、26 条经络对象，画布数量为 1 |
| 在结构页先选呼吸系统，再选女性 GLB | 载入后保留呼吸系统筛选，器官索引可点击 |
| 检查网络与布局 | 本机文件选择流程中模型网络请求与写请求均为 0，浏览器错误为 0，390 像素教学页无横向溢出 |

## 复测

在提供男女 GLB 和配套经络文件的本机 8020 服务上，安装项目锁定的 npm 依赖并使用 Chrome 运行 `node deploy/verify_model_loading.cjs`。脚本在隔离的浏览器会话中模拟预览站源地址，文件从回环地址读取，只交给浏览器的文件选择控件。

以上为软件功能验证。几何计数来自当前教学模型。
