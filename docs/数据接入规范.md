# 队友数据接入规范（医学生 3D 教学系统）

> 目标：队友提供“病例—时间—阴阳气血—用药事件”数据，系统导入后驱动 3D 人体与经络变化，帮助医学生理解中医理论。  
> 当前支持 **CSV** 与 **JSON**；页面 `web/dataset.html` 本地解析，不上传。  
> 演示文件 `web/data/dataset_demo.csv` 是**格式演示数据，不是真实病例/实验结果**。

## 1. 数据应该长什么样

每个案例至少要有 **2 个时间点**（推荐 0、7、14、28 天）：

- 案例元信息：匿名编号、案例名、证候、方剂示例、相关脏腑/经络；
- 时间点：`day`、`yin`、`yang`、`qi`、`blood`、`stagnation`、`inflammation`、`blocked_meridian`；
- 用药事件：`event`、`medication`（只写方名/事件，不写剂量）；
- 来源与许可：`dataset_name`、`contributor`、`source`、`license`。

## 2. CSV / TSV 格式

模板：`web/data/dataset_template.csv`

- 支持逗号 `,`、分号 `;`、Tab 分隔；页面会自动识别，并在“数据信息 → 格式”显示。
- `.tsv` 文件按 Tab 解析；含分隔符的字段请用英文双引号包裹。
- 页面可切换“曲线 / 表格”查看同一组数据；表格可横向滚动。

| 列 | 必填 | 类型/取值 | 说明 |
|---|---|---|---|
| dataset_name | 建议 | 文本 | 数据集名称；会显示在页面 |
| contributor | 建议 | 文本 | 数据提供者（队友姓名/团队代号） |
| source | 建议 | 文本 | 来源：教材/专家设定/教学参数/脱敏病例 |
| license | 建议 | 文本 | 使用许可；未提供页面会提示“许可待补” |
| case_id | **必填** | 文本 | 匿名编号，如 `CASE-001`；不要用姓名/住院号 |
| case_name | 建议 | 文本 | 教学案例名，如“阳虚怕冷教学案例” |
| pattern | 建议 | 文本 | 证候，如“肾阳虚”“肝郁气滞” |
| formula | 可选 | 文本 | 经典方名示例；不要写剂量 |
| organs | 建议 | `Kidneys\|Spleen` | 脏腑键名，多个用 `\|`；中文名也支持 |
| meridians | 建议 | `KI\|DU` | 经络代码或中文名，多个用 `\|` |
| day | **必填** | 数字 | 天数，推荐 0–28；可小数 |
| yin | **必填** | 0–1 | 阴；支持 0–100 的百分数（自动除以 100） |
| yang | **必填** | 0–1 | 阳 |
| qi | 建议 | 0–1.2 | 气机；1 为常模 |
| blood | 建议 | 0–1.2 | 血行；1 为常模 |
| stagnation | 建议 | 0–1 | 瘀滞；越大越瘀 |
| inflammation | 建议 | 0–1 | 虚火/炎症教学参数 |
| blocked_meridian | 可选 | `KI`/`LR`/`DU`… | 阻滞经络；留空表示无明显阻滞 |
| event | 可选 | 文本 | 如“用药前”“开始用药”“随访”“末次随访” |
| medication | 可选 | 文本 | 方名/用药事件；**不要填剂量** |
| note | 可选 | 文本 | 教学备注；不要写可识别身份信息 |

### 2.1 脏腑键名

`Heart`、`Liver`、`Spleen`、`Lungs`、`Kidneys`、`Stomach`、`SmallIntestine`、`LargeIntestine`、`Gallbladder`、`Bladder`、`Pancreas`、`Brain`、`Trachea`、`Airways`。  
也支持中文：心、肝、脾、肺、肾、胃、小肠、大肠、胆、膀胱、胰、脑、气管、支气管。

### 2.2 经络代码

`LU` 肺经、`LI` 大肠经、`ST` 胃经、`SP` 脾经、`HT` 心经、`SI` 小肠经、`BL` 膀胱经、`KI` 肾经、`PC` 心包经、`TE` 三焦经、`GB` 胆经、`LR` 肝经、`REN` 任脉、`DU` 督脉。  
也支持中文名直接填写。

## 3. JSON 格式

适合队友一次传多个案例、带元信息：

```json
{
  "meta": {
    "dataset_name": "医学生教学参数集",
    "contributor": "队友A",
    "source": "专家设定的教学参数，不是患者测量",
    "license": "仅用于本项目教学",
    "is_demo": false
  },
  "cases": [
    {
      "case_id": "CASE-001",
      "case_name": "阳虚怕冷教学案例",
      "pattern": "肾阳虚",
      "formula": "金匮肾气丸",
      "organs": ["Kidneys", "Spleen", "Bladder"],
      "meridians": ["KI", "DU", "BL"],
      "series": [
        { "day": 0,  "yin": 0.62, "yang": 0.22, "qi": 0.55, "blood": 0.70, "stagnation": 0.38, "inflammation": 0, "blocked_meridian": "KI", "event": "用药前", "medication": "" },
        { "day": 7,  "yin": 0.58, "yang": 0.32, "qi": 0.72, "blood": 0.80, "stagnation": 0.25, "inflammation": 0, "blocked_meridian": "KI", "event": "开始用药", "medication": "金匮肾气丸" },
        { "day": 28, "yin": 0.52, "yang": 0.46, "qi": 0.95, "blood": 0.95, "stagnation": 0.08, "inflammation": 0, "blocked_meridian": "", "event": "末次随访", "medication": "金匮肾气丸" }
      ]
    }
  ]
}
```

也接受：
- 顶层直接是案例数组 `[{...}, {...}]`；
- 单个案例对象（含 `series`）；
- `rows` 数组（字段同 CSV）；
- `points` 作为 `series` 的别名。

## 4. 数值与插值规则

- `day` 排序；同一天重复时保留最后一条并给提示。
- 两个数据点之间**线性插值**；`blocked_meridian` 在两点中点切换。
- 只有一个数据点时，页面显示单点，不播放时间轴。
- `yin`/`yang` 建议 0–1；若填 11–100，自动按百分比处理。
- `qi`/`blood` 建议 0–1.2；`stagnation`/`inflammation` 建议 0–1。
- 超出范围会被截断显示，并在“数据信息”里给出警告；不要依赖静默截断，请先核对原始数据。
- 缺失 `yin`/`yang` 会用 0.5/0.5；缺失 `qi`/`blood` 会用 1.0；页面会显示警告。请尽量补齐。
- 3D 覆盖层/时间轴会显示数据名称、来源状态与“非临床演示数据/许可待补”；不要把这些提示删掉。

## 5. 数据质量与合规

- **匿名**：`case_id` 不得包含姓名、学号、住院号、身份证号、电话。
- **最小化**：只提供教学需要的字段；不要提供完整病史、检查报告、可识别照片。
- **来源**：`source` 要写清是教材/专家设定/教学参数/脱敏病例；不要把教学参数写成“患者实测”。
- **用药**：只写方名/事件，不写剂量、煎服法、加减；系统不做处方推荐。
- **疗效**：数据只用于教学可视化；不得写成“治愈/有效/疗效保证”。
- **真实病例**：如使用真实临床数据，必须先脱敏并取得伦理/医院许可；原始数据只放 `challenge_cup/data/real/`（已 gitignore），不要提交到 Git。
- **许可**：`license` 必须由数据提供者确认；不确定就写“仅用于本项目教学，未授权再分发”。

## 6. 队友交付方式

1. 从 `web/data/dataset_template.csv` 复制一份，改名 `dataset_<主题>.csv`；
2. 按上表填 3–8 个教学案例，每个案例 3–5 个时间点；
3. 本地打开 `web/dataset.html` → “选择数据文件”导入，检查页面警告；
4. 把文件放到 `web/data/` 并在 `docs/数据接入规范.md`/PR 说明中写清来源与许可；
5. 如果数据含真实病例，**不要**放 `web/data/`，交给团队放 `challenge_cup/data/real/`，只把脱敏后的教学参数版本放入演示目录。

## 7. 验收清单

- [ ] 每个案例有 `case_id`，且不含身份信息；
- [ ] 每个案例至少 2 个时间点，`day` 递增；
- [ ] `yin`/`yang`/`qi`/`blood`/`stagnation`/`inflammation` 在合理范围；
- [ ] `organs`/`meridians` 使用规范键名；
- [ ] `medication` 只有方名/事件，无剂量；
- [ ] `source`/`license` 已写；
- [ ] 页面导入后无 P0 警告（未知脏腑/经络、缺阴阳等）；
- [ ] 3D 与曲线随时间轴变化，事件点可见；
- [ ] 明确标注“教学演示，不是诊断/疗效证据”。
