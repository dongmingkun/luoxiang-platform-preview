## 理论内容

1. **昼夜循行（卫阳）**：昼行阳分（体表、六腑），夜行阴分（体内、五脏）；出自《灵枢》卫气行。
2. **经脉循行**：督脉为阳脉之海，上行入脑、下贯腰骶；三阳经主表主外，由躯干向四肢末梢布散；三阴经中藏阳，从四肢内侧回纳归脏。
3. **脏腑升降**：肾阳为根向上蒸腾；脾阳主升，上输心肺；心阳温通血脉、心火下潜暖肾；肺阳宣发肃降；肝阳升发条达。规律：阳宜升而忌浮散，宜潜藏而忌沉埋。
4. **功用概括**：温煦、推动、固摄、防御、气化；阻滞则郁、不足则寒、浮越则虚火外飘、脱散则危。
5. **阴阳动态 · 阳主阴从**（v1.3 新增，定位是帮助理解阴阳动态运行，不绑定单一学派）：阳主升主外、阴主降主内，阴阳是动态主从而非对等僵持；坎中一阳——真阳藏于肾水为总根；昼阳行表卫外、夜阳入阴宅归根潜藏。扶阳派（郑钦安《医理真传》）为其系统阐发者之一，根在《内经》「阳气者，若天与日」。
6. **一句话**：肾阳为本，借中土升降，循督脉、三阳经，昼出表夜入里，周而复始，阴中藏阳，阳根于下。

## 交互映射

- **昼 / 夜**：切换场景灯光；昼高亮六腑 + 三阳经，夜高亮五脏 + 三阴经；2D 图切换卫阳出表/入里箭头。
- **督脉**：高亮 DU 与肾/脑。
- **三阳**：高亮胃、小肠、大肠、胆、膀胱与手足三阳经。
- **三阴**：高亮五脏与手足三阴经。
- **脏腑**：高亮五脏，显示肾-脾-心-肺-肝升降图。
- **阳主阴从**（v1.3 新增）：肾根常明；昼 = 肾/脑 + 督脉 + 三阳经高亮（阳主于外，阴从于内）；夜 = 肾 + 五脏 + 督脉 + 三阴经高亮（阳入阴宅温养）。随昼夜切换自动重算。
- **全部**：回到当前昼夜的综合高亮。

## 六经气血差异（v1.3 · 与主演示共用 meridians.js）

按《素问·血气形志》六经气血多少，每条经络的流光有**粗细 / 快慢 / 急缓 / 浮沉**之别：

- 阳明（ST/LI）多气多血：最粗、最快、最急；太阳（BL/SI）多血少气：最浮于表（背为阳之表）；少阳（GB/TE）少血多气：枢，半表半里。
- 太阴（SP/LU）多气少血：阴中最浮；少阴（KI/HT）少血多气：主藏，沉而缓；厥阴（LR/PC）多血少气：最深。
- 督脉（阳脉之海）浮而急；任脉（阴脉之海）沉而缓。
- 证候差异：阳虚 → 阳经先衰（更慢更暗更缓，督脉尤甚）；阴虚 → 阴经受累、阳经虚火浮躁（更快更急更亮）；瘀滞 → 整体脉势变钝变慢，阻滞经紫变反向。

## 边界

- 页面是理论教学整理，不构成诊断或处方；经典条文以《灵枢》等原文和教材为准。
- 「阳主阴从」小节为帮助理解阴阳动态的教学视角，不构成对特定学派的疗效背书。
- 3D 经络方向是教学示意，不替代针灸经络定位；真实经气流注方向以教材/临床为准。
- 脏腑高亮只表示理论关联，不表示器质性病变。
- 昼夜灯光是视觉表达，不对应真实生理时钟或睡眠医学建议。
