日期：2026-11-03。用户授权本次同时优化模型与展示，仍分别在模型仓/平台仓工作，本地提交，不推送，不修改完整开发仓。

## 当前名称

当前产品名称为 **络象经纬**：以“络”指结构联系，“象”指可视表达，“经纬”指空间与经络的组织关系。平台页面标题、页眉、智能体欢迎语、当前 README 和选题名称已同步。历史截图、工程记录与 Git 历史保留原貌。

本次做过公开网页精确词检索，名称作为当前项目展示名使用；未进行商标/软件名称登记查询，不声明全网唯一或已注册。

## 直接使用

```powershell
# 在平台仓根目录；模型位于同级 tcm-human-model/web/assets/
powershell -ExecutionPolicy Bypass -File deploy/start_preview.ps1
# 浏览器打开 http://127.0.0.1:8020/structure.html
```

1. 页面“载入本机 GLB 模型”选择队长从模型仓手动取得的教学文件；文件通过浏览器 File API 读取，不上传，不存入平台仓。
2. 推荐选择模型仓 `rhino/output/structure_atlas/structure_atlas_male.glb` 或 `structure_atlas_female.glb`。也兼容原 `anatomy_male.glb` / `anatomy_female.glb`，但旧模型的肺轮廓不会自动升级。
3. “结构总览 / 呼吸 / 循环 / 消化 / 泌尿 / 神经 / 淋巴”按已有器官筛选；其他结构减淡作为空间参照。这些分组不代表完整系统模型。
4. 开关体表、骨骼与标注；体表透明度可调。右侧搜索器官，或点击模型/引导线名称，聚焦并“单独观察”；“恢复整体 / 复位”回到整体。
5. “结构分离展示”展开遮挡器官，页面显示展示位移说明；判断原位关系前应复位。颜色用于区分结构，不表示健康或疾病程度。
6. 可切正面/背面/左右侧与环绕。女性模型为比例重建；不是独立女性扫描。

“载入已整合版”只读取平台本地路径 `assets/anatomy_<sex>.glb`。在 8020 预览服务下，该路径由服务从同级模型仓按文件名映射，相当于队长本地手动整合；不会去 GitHub/Gitea 下载。平台 Git 仍不含模型，也不要求队长上传整合过程。

## 模型仓的 Rhino+GPT 交付

模型仓新增 `rhino/scripts/build_structure_atlas.py` 与 `rhino/STRUCTURE_ATLAS.md`，生成男女各原位/展开 `.3dm` 及教学 GLB。详细网格继承已有许可资产；肺包络改为参数化收尖轮廓与示意沟槽。其他器官网格、体表隐私与节点名保持原来源版本。

Rhino 原生文件包含独立图层/材质、14 个双语 TextDot、引导线、26 条经络参考和四个命名视图。生产 GLB/FBX/Blender 文件没有覆盖；这是单独教学变体。模型与生成脚本只在模型仓，平台只放页面代码、说明与带署名的工程截图。

当前通过 rhino3dm/openNURBS 生成、回读与网格一致性检查；尚未在 Rhino GUI 里实机审阅，亦未取得专家对形态准确性的验收。不能把可打开、闭合网格或交互通过写成临床精度或教学效果证据。
