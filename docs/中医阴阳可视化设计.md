# 中医阴阳二气 3D 可视化 · 设计说明

> 目标：把中医的「阴阳、气血、经络、子午流注、丹田」从抽象概念转译为**可观察、可对比、可交互**的三维动态图形。  
> 定位：教学 / 科普 / 答辩演示，不作为诊断工具。

---

## 1. 理论依据与转译原则

### 1.1 阴阳

| 中医关系 | 可视化策略 |
|---|---|
| 对立制约 | 青蓝（阴）与橙红（阳）互补色；两组参数此消彼长 |
| 互根互用 | 太极双鱼互相包含；阴阳滑杆不会把另一方彻底归零，最低保留 5% 基底光 |
| 消长平衡 | 正常态 `yin = yang = 0.5`，太极匀速、双色等亮；失衡时旋转加速、色比偏移 |
| 相互转化 | 状态切换使用插值而非硬切；阳虚/阴虚的恢复过程会看到颜色与流速连续过渡 |

参数：`yin`、`yang` 均为 0–1；`YangRatio = yang / (yin + yang)`；`Imbalance = |yang - yin|`。

### 1.2 气血

- **气为血之帅**：气机 `qiFlow` 同时驱动经络光点速度与血脉心搏幅度；气机下降时血脉也会变慢。
- **血为气之母**：血行 `bloodFlow` 影响血脉亮度；血瘀时经络光点也会因失养而减弱。
- **双层结构**：经络管径约 7 mm、速度快、脉冲密；血脉管径约 9 mm、深红、带心跳包络。两层叠加形成「气行血行」的层次感。

### 1.3 经络

- 十二正经左右各一（26 条，含任督二脉），全部使用同一套 Catmull-Rom 控制点。
- 控制点顺序即**经气流注方向**：手三阴从胸走手、手三阳从手走头、足三阳从头走足、足三阴从足走腹胸；任脉自下而上，督脉沿脊背上行过头面。
- 每条经脉带 `polarity`（yin/yang）、`element`（木火土金水）、`organ`、`pairedWith` 元数据，为后续穴位、五行配色和证候推理留接口。

### 1.4 子午流注

12 时辰与当令经脉：

| 时辰 | 时间 | 经脉 | 时辰 | 时间 | 经脉 |
|---|---|---|---|---|---|
| 子时 | 23–01 | 胆经 | 午时 | 11–13 | 心经 |
| 丑时 | 01–03 | 肝经 | 未时 | 13–15 | 小肠经 |
| 寅时 | 03–05 | 肺经 | 申时 | 15–17 | 膀胱经 |
| 卯时 | 05–07 | 大肠经 | 酉时 | 17–19 | 肾经 |
| 辰时 | 07–09 | 胃经 | 戌时 | 19–21 | 心包经 |
| 巳时 | 09–11 | 脾经 | 亥时 | 21–23 | 三焦经 |

- 腰部 12 段虹环 = 12 经脉；当前时辰段高亮，指针随分钟推进。
- 对应经脉在人体上获得额外亮度与脉冲，形成「环 → 人」的视觉对应。
- 默认 0.55 小时/秒，约 44 秒走完一个昼夜；可暂停、拖动时间轴。

### 1.5 丹田

| 丹田 | 对应 | 颜色 | 动效 |
|---|---|---|---|
| 下丹田 | 精 | 琥珀金 | 缓慢呼吸，气机越足越亮 |
| 中丹田 | 气 / 宗气 | 金橙 | 与心搏轻微同步 |
| 上丹田 | 神 | 冷白青 | 高频微脉动，保持通透感 |

### 1.6 写实解剖版（当前）

当前版本不再使用代谢球示意人体，而是用 **BodyParts3D 4.0** 开放解剖数据重建：

- 完整皮肤、87 块骨骼（颅骨/脊柱/肋骨/胸骨/骨盆/肩胛/锁骨/四肢长骨）、五脏六腑、脑、气管与支气管树；
- 肺实质在数据集中缺失，使用程序化双肺补建；心脏由心室壁、心房壁与心腔组合；
- 经络控制点逐点投影到真实皮肤表面，保证管状网格贴合真实体表；
- 器官按五脏五行着色，并保留器官本身的明暗/材质层次：

| 五脏 | 五行 | 颜色 | 状态动效 |
|---|---|---|---|
| 心 | 火 | 朱红 | 随 BPM 搏动；阴虚/虚火时加快、偏亮 |
| 肝 | 木 | 青绿 | 气滞血瘀时变紫、变暗，对应肝经阻滞 |
| 脾 | 土 | 土黄 | 阳虚时变暗 |
| 肺 | 金 | 白 | 呼吸式缩放；阳虚时变暗、阴虚偏亮 |
| 肾 | 水 | 蓝 | 阳虚明显变暗，阴虚偏亮 |

其余器官（胃、小肠、大肠、胆、膀胱、胰、脑、气管/支气管）也以独立对象渲染，可单独开关。UI 提供「显示器官 / 显示骨骼」开关，快捷键 `O` / `K`；五脏图例固定显示五行色。

## 2. 状态模型

`TcmState` 是唯一的状态载体：

```csharp
float yin;          // 0..1
float yang;         // 0..1
float qiFlow;       // 0..2，1 为正常
float bloodFlow;    // 0..2，1 为正常
float stagnation;   // 0..1
float inflammation; // 0..1，虚火/热象
string blockedMeridian; // 如 "LR" / "KI" / "HT"
Color bodyTint;
```

### 2.1 映射到 Shader / 动效

| 状态量 | 主要影响 |
|---|---|
| `qiFlow` | 经络 `_FlowSpeed`、`_Intensity`、丹田亮度、太极转速、流注指针速度观感 |
| `bloodFlow` | 血脉 `_FlowSpeed`、`_Intensity`、`_Bpm`（62–90） |
| `yin` / `yang` | 阴经/阳经各自的亮度权重、太极双色亮度、背景/体表色温 |
| `stagnation` | 阻滞经脉的 `_Blockage`、流动反向、紫色瘀点数量与尺度、体表紫色偏移 |
| `inflammation` | 体表偏红、线框偏暖、太极边缘闪烁增强 |
| `blockedMeridian` | 定位哪一条经脉进入阻滞状态，并生成瘀点 |

### 2.2 四个预设

| 预设 | yin | yang | qi | blood | 瘀滞 | 虚火 | 阻滞经 | 视觉关键词 |
|---|---:|---:|---:|---:|---:|---:|---|---|
| 正常 | 0.50 | 0.50 | 1.00 | 1.00 | 0.00 | 0.00 | — | 平衡、匀速、通透 |
| 阳虚 | 0.62 | 0.22 | 0.55 | 0.70 | 0.38 | 0.00 | 肾经 KI | 冷、慢、暗、迟滞 |
| 阴虚 | 0.20 | 0.64 | 1.18 | 0.88 | 0.08 | 0.72 | 心经 HT | 热、快、燥、浮动 |
| 气滞血瘀 | 0.48 | 0.44 | 0.34 | 0.30 | 0.90 | 0.20 | 肝经 LR | 紫、堵、反向、瘀点 |

切换预设时使用 0.9 s `SmoothStep` 插值；自定义滑杆使用 0.28 s，保证即时手感。

### 2.3 阻滞表现算法

1. 找到 `baseId == blockedMeridian` 的左右两条经脉。
2. Shader 在弧长 `_BlockPosition ≈ 0.46` 处生成一个紫色高亮区，越靠近越暗、越紫。
3. 流动方向取反（`_Direction = -1`），速度降到 18%，读作「气行受阻、浊气反流」。
4. 沿该经脉弧长 0.24 / 0.38 / 0.52 / 0.66 / 0.80 放置 5 个紫色瘀点，大小随 `stagnation` 呼吸。
5. 血脉整体变暗、变慢，配合「气滞则血瘀」。

## 3. 视觉语法

| 维度 | 正常 | 异常 |
|---|---|---|
| 色彩 | 青蓝 / 橙红平衡，体表冷白 | 阳虚偏蓝、阴虚偏红、瘀滞偏紫 |
| 亮度 | 经络均匀明亮 | 病经变暗或出现高对比紫斑 |
| 运动 | 匀速层流 + 心跳 | 流速下降 / 反向 / 局部湍流 |
| 形态 | 人体轮廓清晰、线框规整 | 瘀点聚集、太极旋转失稳 |
| 节奏 | 呼吸 1.15 Hz、心跳 72 BPM | 阳虚更慢、阴虚更快、瘀滞紊乱 |

### 3.1 场景分层（从后到前）

1. 深色渐变背景 + 指数雾
2. 舞台圆台、三层光环、36 个刻度、背后淡光柱
3. 全息人体（加性混合）+ 线框能量皮肤
4. 真实皮肤（半透明外壳）→ 骨骼（象牙白）→ 五脏六腑（五行色，随证候搏动/呼吸）
5. 血脉（深红心搏）→ 经络（青蓝/橙红流光）→ 瘀点（紫色）
6. 太极盘 + 双环 + 轨道光珠
7. 三丹田光球
8. 子午流注环
9. UI 控制面板 + 五脏图例（Screen Space Overlay）

### 3.2 镜头

- 默认 3/4 前视，距离 3.35 m，FOV 38°；目标点约在胸腹之间（y = 0.92）。
- 闲置 4 s 后以 3.2°/s 自动环绕；拖拽立即接管。
- `F` 聚焦躯干（距离 1.9 m），便于展示太极、丹田与经络交汇。
- 泛光强度 0.62、阈值 1.05，只让高亮流光溢出，不让整体发灰。

## 4. 色彩与材质规范

| 用途 | 色值（近似） | 说明 |
|---|---|---|
| 阴经 | `#23A0FF` | 青蓝，避免纯青导致与背景混淆 |
| 阳经 | `#FF5220` | 朱橙，与阴经形成互补 |
| 血脉 | `#D10A12` | 深红，带心搏 |
| 瘀滞 | `#A82EFF` | 紫，区别于阴经的蓝 |
| 体表正常 | `#59C7FF` | 冷白青 |
| 下丹田 | `#FFB84D` | 琥珀金 |
| 上丹田 | `#C7F0FF` | 冷白青 |

Shader 层：所有发光物体使用 **加性混合（Blend SrcAlpha One）**，不写深度；人体也是加性全息，因此经络可以透过体表看到，符合「内景透视」的视觉隐喻。太极使用 Alpha Blend 以保持正负形的可读性。

## 5. 演示脚本建议（答辩 / 讲解）

1. **正常态**：先看整体，指出青蓝与橙红两组经络、任督二脉、心搏血脉、太极与三丹田。
2. **打开子午流注**：拖动时间轴到寅时，说明肺经当令，人体肺经同步增亮；再拖到午时看心经。
3. **阳虚**：观察整体变冷、流速下降、肾经紫色阻滞；解释「阳不制阴、寒从内生」。
4. **阴虚**：观察体表转暖红、流速偏快、心经瘀点；解释「阴不制阳、虚火内生」。
5. **气滞血瘀**：聚焦躯干，观察肝经反向流动与紫色瘀点；解释「不通则痛」。
6. **自定义滑杆**：现场把气机拉低、瘀滞拉高，说明参数模型是可解释、可连续变化的，而不是四段预设动画。

## 7. 边界与声明
